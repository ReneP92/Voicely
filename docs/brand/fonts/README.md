# Geist

Unmodified variable TrueType font, weights 100-900, from [Google Fonts / Geist](https://github.com/google/fonts/tree/main/ofl/geist). Licensed under the SIL Open Font License 1.1; see `OFL.txt`.

Upstream file: `Geist[wght].ttf`. Git blob SHA: `f63f0afc6390323715972b6645115485f37cc9f4`. Locally named `Geist.ttf` for uncomplicated asset URLs. The build uses weight 700 for the outlined wordmark, with slightly tightened spacing. Interface text uses live Geist, usually 400, 500 or 600.

Keep the license when redistributing this font. Do not replace it with a system-installed font during export. The exported SVGs contain outlines and need no installed fonts.
